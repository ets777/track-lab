Эксперимент отвечает на один вопрос: изменило ли это что-нибудь? Вы задаёте период, указываете, за чем хотите следить, и по желанию обещаете, что будете делать. Затем TrackLab сравнивает произошедшее с неделей до начала эксперимента.

## Индикаторы — что измеряется

Индикатор — любая сущность, которую вы уже отслеживаете: метрика (Настроение), действие (Бег), тег или элемент списка. У каждого индикатора есть направление:

| Направление | Значение |
| --- | --- |
| Вверх | Вы ожидаете рост |
| Вниз | Вы ожидаете снижение |
| Любое | Только наблюдаете, провалиться не может |

Для метрик значение — среднее из записанных вами значений. Для действий, тегов и элементов — суммарное затраченное время. Эксперимент может содержать до трёх индикаторов.

## Правила — что вы обещаете

Правило — обязательство на весь период, например «Бегать не менее 3 раз в неделю». Правила проверяются по дням, неделям или месяцам и появляются на панели в виде чек-листа. Правила необязательны — добавляйте их, когда эксперимент о смене привычки, а не просто о наблюдении. Эксперимент может содержать до трёх правил.

## Базовая линия

Начальное значение каждого индикатора берётся из семи дней перед датой старта. Форма показывает его, как только вы выберете индикатор и период. Если данных за ту неделю нет, TrackLab сообщит об этом и вместо неё возьмёт за базу первую неделю эксперимента.

## Создание

Откройте Лаборатория → Эксперименты → +. Заполните:

1. Название — что вы проверяете, например «Утренние пробежки».
2. Период — даты начала и конца. По умолчанию один месяц.
3. Индикаторы — нажмите «Добавить» и выберите из списка.
4. Правила — нажмите «Добавить» и выберите из списка.

Если список выбора пуст или в нём нет нужного, используйте кнопки «Новая метрика / Новое действие / Новый тег / Новый элемент / Новое правило», закреплённые внизу списка. Они открывают ту же форму, что и отдельные страницы, сохраняют её и сразу подставляют результат — вы не покидаете эксперимент. Это вложено: создавая здесь правило, можно так же создать и действие для него.

## Как завершается

Эксперимент идёт до даты окончания, затем TrackLab отмечает его как Успех или Провал. Он может провалиться и раньше:

| Итог | Когда |
| --- | --- |
| Успех | Дата окончания прошла, и каждый индикатор вверх/вниз изменился как ожидалось |
| Провал — тренд не достигнут | Дата окончания прошла, а индикатор изменился не туда |
| Провал — низкая дисциплина | После первой недели выполнено менее 50% проверок правил |
| Провал — нет начальных значений | После первой недели у трендовой метрики так и нет значения для сравнения |
| Провал — нет итоговых значений | Эксперимент закончился без данных для сравнения |

Индикаторы со значением «любое» никогда не приводят к провалу. Дисциплина учитывается только если у эксперимента есть правила — эксперимент лишь для наблюдения не может провалиться по дисциплине.

## Пока он идёт

Продолжайте записывать активности как обычно. Это единственный ввод, который нужен эксперименту; он читает те же записи, что и остальное приложение. Панель показывает чек-лист правил для текущего периода, так что ежедневный цикл не меняется.
