Резервная копия — один зашифрованный файл со всей вашей базой. Создайте её через «Настройки → Резервная копия», а верните через «Восстановить». Файлы лежат в Documents/TrackLab/backups.

## Автоматические копии

Задайте расписание в «Настройках» — ежедневно, еженедельно или ежемесячно. Автоматическая копия создаётся, только если вы записали что-то новое с прошлого раза, поэтому неизменные данные не сохраняются заново.

## Пароли и совместимость

Задайте пароль, чтобы зашифровать файл своим ключом; без него копия всё равно сохранится, просто без этого ключа. При восстановлении пароль спрашивается только тогда, когда нужен. Копии старых версий полностью совместимы — TrackLab переносит их при восстановлении.
