The library is where your lists live. A list is your own set of items you can attach to an activity — for example, a list named "Emotions" holds items like "angry, happy, calm". Create lists and items in Lab.

## When items appear

A list's items show up in the activity form when you select an action or tag linked to that list. A list linked to nothing is always available. This keeps the form short — you only see the vocabulary that fits what you did.
