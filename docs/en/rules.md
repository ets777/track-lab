A rule is a commitment you can hold yourself to, for example "run at least 3 times a week". Rules show up on the dashboard as a checklist and can drive experiments.

## How a rule is built

Pick a subject — an action, tag or list item — then what to measure about it:

- number of times it happened,
- total time spent on it, or
- number of days it happened.

Add a target with ≥ or ≤ and a period: day, week or month. Optional start and end dates limit when the rule runs; an optional time window limits which activities count toward it.

## Checking

TrackLab evaluates the rule once per period and marks it met or missed. Inside an experiment, your share of met checks — the uptime — is one of the things that decides whether the experiment succeeds.
