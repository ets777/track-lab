The dashboard is the home screen: a grid of widgets you arrange in Dashboard settings. Each widget resizes to its cell, so the layout fits any screen.

## Widgets

- Quick add — one tap to start a new activity or tag.
- Navigation — tiles to the sections you use most.
- Rules — the checklist for the current period, a few rules at a time.
- Metric graph — one metric over time.
- Library graph — time spent on an action, tag or item.
- Experiment — a running experiment at a glance.
