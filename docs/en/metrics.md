A metric is a number you record on an activity — Mood, Energy, Weight. TrackLab ships a few; add your own in Lab.

## When a value counts

A metric value is treated as the state at the activity's **end** time, not its start. You log activities after they happen, so the value reflects the moment the activity finished. Graphs plot each value at that end time.

## Shape of a metric

Each metric has a step and an optional range (min and max) that bound what you can enter, plus an optional unit shown next to the value. Turn on "show previous value" to see your last entry as a hint while logging.
